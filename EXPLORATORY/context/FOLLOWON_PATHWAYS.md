# Follow-on pathways (horizon, not this paper)

These are larger directions that exceed the June 30 scope. They are here so the agent understands where the work points and can write credible Future Work sentences, and so the owner can decide later which to grow into separate papers. **Do not build these into the journal submission.** All are feasible from existing data (no lab needed) unless noted.

1. **Carbon passports / Digital Product Passport readiness.** UUID-per-unit measured carbon maps cleanly onto DPP unique-identifier requirements (aluminum enters the DPP regime in 2027). Mostly schema work; a `carbon_passport` module already exists. Demonstrable on existing data.

2. **Primary-data-share / PCF exchange (PACT, Catena-X).** The method is the shop-floor generator of the high-primary-share data these exchange frameworks presuppose. Desk/mapping work; can compute the oil pump's manufacturing-stage primary data share from existing data.

3. **UUID labels as ground truth for energy disaggregation (NILM inversion).** Operation-labeled 1 Hz data is exactly the training data disaggregation research lacks. Classification runs on existing data; multi-machine attribution can be tested via synthetic superposition of real streams. Strong standalone ML paper.

4. **Benchmark dataset + attribution-vs-prediction bridge.** Publishing the operation-labeled, replicated dataset creates a community resource and positions attribution as the label factory for the ML-prediction literature. Gated by institutional release permission, not by data access.

5. **Allocation-rule falsification with measured ground truth.** Body/lid already breaks mass-based allocation; quantifying each rule's error against measured attribution is a methodological contribution. (Also appears as a *this-paper* exploration in EXPANSION_DIRECTIONS; the larger multi-mix version is the follow-on.)

6. **Energy signatures for tool-wear / process health.** Same meter stream serving condition monitoring is the dual-use argument that justifies shop-floor adoption. First analysis (energy vs run order) runs on existing data.

7. **Emission-factor temporal sensitivity.** Re-convert timestamped runs under annual-average vs hourly vs marginal factors using the existing MOER data. Kept strictly distinct from carbon-aware scheduling, which is separate forthcoming work.

8. **Standards-based digital twin / automated LCI.** Formalize the operation-level energy record as a standard information model (ISO 23247, AAS submodels, UPLCI/CO2PE!); demonstrate via replay of recorded data rather than a live loop.

9. **Feature-energy library for design.** Accumulate operation energy against causal features into a measured library with per-feature uncertainty; the JMD-facing program. Thin with two parts; honest as proof of mechanism.

For the submission, exploring these means deciding which two or three deserve a single Future Work sentence that signals the work has a future. The rest stay out.
