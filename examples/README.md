# Examples

This folder is reserved for small, anonymized examples that can run without private lab data, WattTime credentials, Siemens NX, or OpenLCA databases.

Planned examples:

- `watttime_sample/`: tiny WattTime-like CSV for parser and scheduling smoke tests.
- `machine_energy_sample/`: tiny CNC/additive energy trace with documented columns and units.
- `openlca_sample_outputs/`: sanitized LCIA result exports or JSON snapshots.
- `opennx_sample_report/`: sanitized feature-extraction report output.

Do not place real credentials, raw private machine logs, licensed WattTime exports, or OpenLCA databases here unless they are explicitly approved for redistribution.
